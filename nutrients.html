1. 영양소

음식물 속에 들어 있으면서 ✓ 몸을 구성하고, 생명 활동에 필요한 ✓ 에너지원으로 사용된다.

2. 영양소의 종류

1) 영양소의 종류:

( 탄수화물 ), ( 단백질 ), ( 지방 ), ( 무기염류 ), ( 바이타민 ), ( 물 )

2) 각 영양소의 특징

빈칸을 채운 뒤 How? 버튼을 눌러 영양소 분자의 3D 구조와 결합을 살펴보세요.

영양소 기능 많이 들어 있는 음식물
탄수화물
 주로 ( 에너지원 )으로 사용되고, 남으면 지방으로 바뀌어 저장됨 밥, 국수, 빵, 고구마, 감자 등
단백질
 주로 ( 몸을 구성 )하며, 에너지원으로도 이용됨. 살코기, 생선, 달걀, 두부, 콩 등
지방
 에너지원으로 사용되며, 에너지를 ( 저장 )하기도 함. 체온 유지에 도움을 준다. 기름, 땅콩, 깨, 참기름, 버터 등
무기염류
 ( 철 ), ( 칼슘 ), 인 등이 포함되며, 뼈, 혈액 등 몸을 구성하거나 몸의 기능을 조절함. 우유, 멸치, 치즈, 견과류, 해조류 등
바이타민
 비타민 A, B, C, D 등이 있으며, 적은 양으로 ( 몸의 기능을 조절 )함 과일이나 채소
물
 우리 몸의 약 60%~ 70%(가장 많은 비율)를 차지하며, 영양소와 노폐물을 ( 운반 )하고 ( 체온 조절 )함

⇨ 음식물마다 들어 있는 영양소의 종류와 양이 다르므로,
정상적인 생명 활동을 유지하기 위해서는 다양한 음식을 먹어 영양소를 골고루 섭취해야 한다!!☺
