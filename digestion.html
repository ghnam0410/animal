영양소별 소화 효소

빈칸은 클릭하고, 선택지는 골라 보세요. How?를 누르면 효소가 정해진 장소에서 정해진 영양소를 분해하는 3D 모형이 열려요.

1) 탄수화물(녹말) 소화 효소

① ( 아밀레이스 ) : ( 침샘 )과 ( 이자액 )에서 분비되어 녹말을 ( 엿당 )으로 분해한다.

② ( 말테이스 ) : 작은창자에서 분비되어 ( )을 ( )으로 최종 분해한다.

2) 단백질 소화 효소

① ( 펩신 ) : ( 위 )에서 분비된 위액에는 소화효소인 ( 펩신 )과 강한 산성을 띠는 ( )이 들어 있다. 이에 의해 단백질은 크기가 작은 폴리펩타이드로 분해된다.

*염산: ( 펩신 )의 작용을 돕고, 음식물 속의 세균을 ( )한다.

② ( 트립신 ) : ( 이자액 )이 십이지장으로 분비되어 단백질을 분해한다.

③ ( 펩티데이스 ) : 작은창자에서 분비되어 단백질을 최종적으로 ( 아미노산 )으로 분해한다.

3) 지방 소화 효소

① ( 라이페이스 ) : ( 이자액 )이 십이지장으로 분비되어 지방을 ( 지방산 )과 ( 모노글리세리드 )로 분해한다.

*쓸개즙은 소화액이지만 소화효소가 없다.

2. 영양소의 흡수 과정

빈칸을 클릭하고, 그림의 빨간 네모칸도 눌러 보세요. 그림을 누르면 융털 3D 모형이 열려요.

2. 영양소의 흡수 과정 : 소화된 영양소는 대부분 작은창자의 ( 융털 )에서 흡수

1) 포도당, 아미노산, 무기염류 등 수용성 영양소 → ( 모세혈관 (A) )으로 흡수

2) 지방과 같은 지용성 영양소 → ( 암죽관 (B) )으로 흡수

그림을 누르면 융털 3D 모형으로 흡수 과정을 볼 수 있어요

📐 주름과 융털 = 넓은 표면적

작은창자 안쪽 벽에는 주름이 많고, 주름 표면에는 손가락 모양의 융털이 빽빽해요. 표면적이 넓어 영양소를 효율적으로 흡수할 수 있어요.

🚚 흡수된 뒤에는?

모세혈관(A)으로 들어간 영양소는 간을 거쳐 심장으로, 암죽관(B)으로 들어간 영양소는 림프관을 거쳐 심장으로 이동한 뒤 온몸으로 운반돼요.

③ C에서 녹말, 단백질, 지방을 각각 분해하는 소화 효소가 모두 들어 있는 소화액을 작은창자로 분비한다.
