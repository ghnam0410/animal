1. 노폐물의 생성

(1) ( 노폐물 )의 생성 : 세포가 에너지를 얻기 위해 영양소를 분해하는 ( 세포호흡 )을 하면 여러가지 노폐물이 만들어진다.

(2) 세포호흡 결과 생성된 노폐물이 몸 밖으로 나가는 과정

네모칸과 괄호를 눌러 확인하고, 그림을 누르면 3D 노폐물의 길이 열려요

① 탄수화물, 지방, 단백질이 분해될 때 공통적으로 만들어지는 노폐물 : ( 물 ), ( 이산화탄소 )

② ( 단백질 )이 분해될 때는 노폐물로 물, 이산화탄소뿐 아니라 ( 암모니아 )가 만들어진다.

③ 각 노폐물이 몸 밖으로 나가는 과정

• 이산화탄소 : ( 폐 )로 이동해 ( 날숨 )에 포함되어 나감

• 물 : 주로 콩팥으로 이동해 ( 오줌 )에 포함되어 나감. 일부는 폐로 이동해 ( 날숨 )에 포함되어 나감

• 암모니아 : ( 독성 )이 강하므로 ( 간 )에서 독성이 약한 ( 요소 )로 바뀐 후 콩팥으로 이동해 오줌에 포함되어 나감

🔬 심화 탐구 : 노폐물을 분자로 보기

영양소 분자가 쪼개져 이산화탄소·물·암모니아가 되는 과정을 3D 분자 모형으로 보고, 암모니아가 왜 위험한지 화학으로 알아보세요.

2. 배설계

(1) ( 배설 ) : ( 오줌 )을 만들어 요소와 같은 노폐물을 몸 밖으로 내보내는 과정

(2) 배설계 : 오줌의 생성과 배설을 담당하는 기관계. 콩팥, ( 오줌관 ), ( 방광 ) 요도 로 구성됨

괄호를 눌러 확인하고, 그림을 누르면 3D 콩팥 모형이 열려요

① 콩팥의 구조 : 바깥부분인 ( ), 중간부분인 ( ), 가장 안쪽 빈 공간인 ( )

② ( 네프론 ) : 콩팥의 겉질과 속질에 있는 오줌 생성의 기본 단위. 콩팥 하나 당 네프론 약 100만 개

③ 오줌의 배설경로 : 네프론에서 생성 → ( ) → ( ) → ( ) → 요도 → 몸 밖

학습지 연습문제

배운 내용을 바탕으로 정답을 선택해보세요.

1

그림은 노폐물의 생성과 배설 과정을 나타낸 것이다.

이에 관한 설명으로 옳지 않은 것은?

① A는 단백질이다.
② B는 요소이다.
③ 기관 (가)는 간이다.
④ 물의 일부는 날숨으로 배설된다.
⑤ 콩팥은 A에서 생성된 노폐물만 걸러서 오줌으로 배설한다.
2

그림은 사람의 배설 기관을 나타낸 것이다.

이에 관한 설명으로 옳지 않은 것은?

① 혈액의 요소 농도는 A에서보다 B에서 높다.
② B는 콩팥 동맥이다.
③ C에는 네프론이 있어 오줌이 생성된다.
④ D는 오줌이 이동하는 세뇨관이다.
⑤ 오줌은 E에 저장되었다가 F를 통해 몸 밖으로 나간다.
3

그림은 건강한 사람의 배설 기관 A∼D와 A의 내부 구조를 나타낸 것이다. E∼H는 각각 사구체, 세뇨관, 모세 혈관, 보먼주머니 중 하나이다.

이를 설명한 것으로 옳지 않은 것은?

① A는 오줌이 만들어지는 곳이다.
② B는 오줌이 방광으로 이동하는 통로이다.
③ 오줌은 C에 모였다가 D를 통해 몸 밖으로 나간다.
④ 오줌이 생성되어 이동하는 경로는 A → B → C → D이다.
⑤ 네프론은 E, F, H로 이루어져 있다.
