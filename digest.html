2. 소화와 소화 효소

빈칸은 클릭하고, 선택지는 골라 보세요. 그림을 누르면 움직이는 그림이, How?를 누르면 3D 모형이 열려요.

1) 소화의 필요성 : 영양소를 몸에서 이용하려면, 영양소가 ( 세포 안 )으로 흡수 될 수 있을 만큼 ( 작은 크기로 분해 )되어야 한다.

2) ( 소화 ) : 탄수화물, 지방, 단백질 등 음식을 먹어서 섭취한 영양소가 세포 안으로 흡수될 수 있을 만큼 작게 분해되는 과정

① ( ) 소화: 음식물을 잘게 부수고, 소화액과 섞고, 다음 기관으로 이동시키는 과정.

예저작 운동(이), 분절운동(작은창자), 꿈틀 운동(식도, 위, 작은창자, 큰창자)

② ( ) 소화: 화학적 성질이 다른 작은 영양소로 분해되는 과정. 이러한 소화 작용을 하기 위해서는 ( 소화 효소 )가 필요하다.

예아밀레이스: 녹말을 엿당으로 분해한다.

3) ( 소화기관 ) : 소화가 일어나는 데 관여하는 기관 예입, 식도, 위, 작은창자, 큰창자, 간, 이자, 쓸개 등

4) ( 소화계 ) : 여러 소화 기관들로 구성되어 영양소의 흡수와 소화를 담당하는 기관계

① ( ) : 음식물이 직접 통과하는 곳 예입, 식도, 위, 소장, 대장, 항문

② ( ☼ ) : 음식물이 직접 통과하진 않지만 소화관에 소화액을 분비하는 곳 예침샘, 위샘, 이자, 쓸개 등

1침샘
  • • 침을 만들어 입안으로 분비
  • • 침 속 소화 효소 아밀레이스
      : 녹말 → 엿당으로 분해
2간
  • • 쓸개즙을 만들어 쓸개로 보냄
3이자
  • • 이자액을 만들어 작은창자로 분비
4쓸개
  • • 저장된 쓸개즙을 작은창자로 분비
5큰창자
  • • 작은창자보다 굵은 관
  • • 남은 물질에서 물을 흡수
6항문
  • • 남은 물질을 몸 밖으로 내보냄
