학습 목표
✿ 혈액이 순환하는 경로를 설명할 수 있다.

1. 순환계

순환계 : 몸속에서 물질의 운반을 담당하는 기관계로 ( 심장 ), ( 혈관 ), ( 혈액 )으로 이루어져 있음.

⇨ ( 심장 )은 혈액을 끊임없이 받아들이고 내보내는 흐름을 만들어 냄

2. 혈액

1) ( 혈장 ) : 혈액의 약 55%를 차지하는 액체 성분으로 90 %가 ( 물 )로 구성되어 있음.

영양소를 운반하여 세포에 공급하고 세포에서 생긴 이산화 탄소와 노폐물을 받아서 운반

2) ( 혈구 ) : 혈액의 약 45%를 차지하는 세포 성분

적혈구

• 혈구의 대부분을 차지하며, 핵이 없고 가운데가 오목한 ( 원반 모양 )임.

• ( 산소 )를 운반하는 ( 헤모글로빈 )이 있어 혈액이 붉은색으로 보이게 함.

⇨ 헤모글로빈이 산소가 많은 곳에서는 산소와 결합, 산소가 적은 곳에서는 산소와 떨어지는 성질이 있기 때문

백혈구

• 혈구 중에 가장 크고, 그 수는 가장 적음. 핵이 있고 모양이 ( 일정하지 않음 )

• 몸 밖에서 들어온 세균을 잡아먹는 ( 식균 작용 )을 함.

혈소판

• 혈구 중에 가장 작고, 핵이 없는 작은 세포 조각 모양을 함.

• 상처가 났을 때 ( 혈액 )을 ( 응고 )시켜 딱지를 만들고 출혈을 막음.

괄호 속 네모칸을 눌러 확인하고, 그림을 누르면 3D 원심 분리 실험이 열려요

네모칸 A~D를 눌러 이름을 확인하고, 그림을 누르면 3D 혈액 모형이 열려요

2. 혈액의 순환

빈칸은 클릭하고, 선택지는 골라 보세요. How?를 누르면 3D 혈액 순환 모형이 열려요.

1) 혈액 순환 : 심장에서 나간 혈액이 동맥, 모세 혈관, 정맥을 거쳐 다시 심장으로 돌아오는 것

2) 혈액 순환의 목적 : ( 물질의 운반 )과 ( 기체 교환 )

3) 혈액 순환 과정 : ( 온몸 )순환과 ( 허파 )순환으로 구분됨.

① 온몸 순환 : 조직 세포에 ( 산소 , 영양소 )를 공급하고

( 이산화탄소 , 노폐물 )을 받아 심장으로 돌아오는 과정

② 허파순환 : 폐를 지나면서 ( )를 내보내고 ( )를 받아오는 과정

⇨ 혈액은 이와 같은 과정을 끊임없이 반복하며 순환하면서 조직 세포들이 세포 호흡을 하고 에너지를 얻음.

4) 동맥혈과 정맥혈

① 동맥혈 : 폐에서 산소를 받아 ( ) 혈액. 폐정맥, 좌심방, 좌심실, 대동맥을 흐른다.

② 정맥혈 : 조직세포에 산소를 주어서 ( ) 혈액. 대정맥, 우심방, 우심실, 폐동맥을 흐른다.

※ 학습지의 ‘좌심실’은 정맥혈이 지나는 ‘우심실’로 바로잡았어요. (아래 순환 도식의 우심방 → 우심실과 같아요.)

위 그림에 대한 설명으로 옳지 않은 것은?

① 혈액은 A→C→(가), B→D→(라)의 방향으로만 흐른다.
② (라)는 대동맥으로 혈압이 가장 낮다.
③ (다)에는 온몸을 돌고 온 산소가 적은 혈액이 흐른다.
④ A와 C 사이, C와 (가) 사이에는 판막이 있다.
